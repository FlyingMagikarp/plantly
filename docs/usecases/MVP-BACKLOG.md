# Plantly MVP Use-Case Backlog

This document lists the use cases currently expected for the first usable version of Plantly.

The list is a planning aid, not a specification. Individual use cases must still be generated and reviewed before implementation.

Use cases may be added, removed, renamed, split, or superseded as requirements become clearer. Assigned identifiers must not be reused.

## MVP Outcome

When the MVP use cases are implemented, Plantly should allow the user to:

* maintain species knowledge
* maintain a collection of individual plants
* organize plants by location
* quickly record plant care
* retain historical care data
* attach images to plants and care events
* view relevant seasonal care information
* maintain species knowledge through Markdown
* perform a fast care round across the collection

Analytics and reporting are intentionally not required for the first MVP. The MVP should collect and preserve the data required for future analysis.
